# simple-mcp-rust

Building a simple MCP using rust and https://github.com/modelcontextprotocol/rust-sdk

# setup

```
mise install
```

# usage

Run the MCP using [inspector](https://github.com/modelcontextprotocol/inspector).

```
npx @modelcontextprotocol/inspector cargo run
```

# releasing

Run dist to build all targets.

```
dist build --artifacts all
```
